# Retail Project

Proyecto SQL desarrollado como pre-entrega del curso de SQL.

## Descripción

El proyecto representa un sistema básico de ventas de una empresa retail y contiene tres tablas principales:

- clientes
- productos
- ventas

Las tablas incluyen claves primarias, claves foráneas y restricciones de integridad para garantizar la consistencia de los datos.

El proyecto también incluye una carga inicial de datos mediante transacciones, actualización masiva de precios y eliminación controlada de registros.

## Base de datos

La base de datos utilizada se llama:

retail_project

## Ejecución

1. Crear la base de datos `retail_project`.
2. Conectarse a la base de datos `retail_project` en PostgreSQL.
3. Ejecutar el archivo `retail_project.sql`.
4. El script creará las tablas `clientes`, `productos` y `ventas` y realizará la carga inicial de datos.

## Tecnologías utilizadas

- PostgreSQL
- SQL
- pgAdmin 4
